# Marketing Campaign Performance Prediction

## 📌 Project Overview

**Marketing Campaign Performance Prediction** is a multi-brand marketing analytics and machine learning project designed to analyze campaign performance and predict business outcomes.

The project works with marketing campaign data from three leading beauty and personal-care brands:

- **Nykaa**
- **Purplle**
- **Tira**

The solution combines **Python, Pandas, Exploratory Data Analysis (EDA), Machine Learning, and Streamlit** to provide both analytical insights and predictive capabilities.

---

## 🎯 Project Objectives

The main objectives of this project are to:

1. Clean and prepare campaign-level marketing data from multiple brands.
2. Consolidate the individual brand datasets into a master dataset.
3. Engineer business-oriented features such as:
   - Profit
   - Profit Flag
   - Calculated ROI
   - Channel indicators
4. Analyze campaign performance through EDA.
5. Predict campaign **Revenue** using Regression.
6. Predict campaign **Profit/Loss** using Classification.
7. Deploy the trained models through an interactive Streamlit application.

## 🧹 Data Preprocessing

The preprocessing methodology was finalized based on the project requirements.

### Missing Value Treatment

- Missing **Revenue** values were replaced with `0`.
- Missing **Acquisition Cost** values were replaced with the mean.
- Other numerical missing values were handled using the mean where applicable.
- Categorical missing values were handled using the mode where applicable.
- Rows were **not removed simply because they contained missing values**.
- `Campaign_ID` was treated as an identifier and was not used as a model feature.
- Missing `Date` values were retained as missing values.
- The original `ROI` field was not used in the final project models.

## ⚙️ Feature Engineering

Several business and machine-learning features were created.

### Profit

```text
Profit = Revenue - Acquisition_Cost
```

### Profit Flag

```text
Profit_Flag =
    Profit  → if Profit > 0
    Loss    → otherwise
```

### Calculated ROI

```text
Calculated_ROI =
    (Revenue - Acquisition_Cost) / Acquisition_Cost
```

### Channel Indicators

Individual binary indicators were created for:

- Google
- WhatsApp
- YouTube
- Email
- Instagram
- Facebook

These features allow the models to work with individual marketing channels.

# 🤖 Machine Learning

Two machine-learning approaches were developed.

## 1. Regression — Revenue Prediction

### Objective

Predict the expected **Revenue** generated by a marketing campaign.

### Model

**Gradient Boosting Regressor**

Configuration:

```python
GradientBoostingRegressor(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=5,
    random_state=42
)
```

### Features

The regression model uses numerical and categorical campaign features, including:

- Duration
- Impressions
- Clicks
- Leads
- Conversions
- Acquisition Cost
- Engagement Score
- Calculated ROI
- Channel indicators
- Year
- Month
- Day of Week
- Campaign Type
- Target Audience
- Channel Used
- Language
- Customer Segment
- Company Name

`Campaign_ID` is excluded because it is an identifier.

### Model Performance

| Metric | Result |
|---|---:|
| MAE | 10,824.80 |
| MSE | 332,778,151.04 |
| RMSE | 18,242.21 |
| R² | 0.9986 |

The Gradient Boosting Regressor was selected as the final regression model after comparing diagnostic model performance.

---

## 2. Classification — Profit/Loss Prediction

### Objective

Predict whether a campaign is expected to result in:

- **Profit**
- **Loss**

### Model

**Gradient Boosting Classifier**

Configuration:

```python
GradientBoostingClassifier(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=5,
    random_state=42
)
```

### Target

`Profit_Flag`

Encoded as:

```text
Loss   → 0
Profit → 1
```

### Features

The classification model uses:

- Duration
- Impressions
- Clicks
- Leads
- Conversions
- Acquisition Cost
- Calculated ROI
- Engagement Score
- Channel indicators
- Campaign Type
- Target Audience
- Channel Used
- Language
- Customer Segment
- Company Name

`Campaign_ID`, `Profit`, and `Revenue` are not used directly as model features.

### Model Performance

| Metric | Result |
|---|---:|
| Accuracy | 1.0000 |
| Precision | 1.0000 |
| Recall | 1.0000 |
| F1 Score | 1.0000 |

Confusion Matrix:


The classification model achieved perfect performance on the held-out test set under the finalized project methodology, which includes `Calculated_ROI` as an approved classification feature.
